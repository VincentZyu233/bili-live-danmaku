# 常用各种语言测试文案

用于测试 Edge TTS 的语言识别和多语言音色。建议先通过桌面快捷方式启动服务，然后每隔 2–3 秒发送一条，避免 B站弹幕限流。

## 中英日混排测试

```text
かなちゃん、你好，Hello! 今天也辛苦啦。
```

预期会拆成日语、中文和英语片段，并分别使用对应音色。

## 日文昵称专项

日文昵称的自动识别需要使用带平假名或片假名的观众账号。该账号发送：

```text
こんにちは。今日もかわいいね！
```

预期昵称使用日语声音，后面的中文正文继续使用中文声音。
